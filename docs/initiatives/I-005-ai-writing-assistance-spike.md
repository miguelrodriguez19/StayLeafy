# I-005 — AI writing-assistance spike

| Field      | Value      |
|------------|------------|
| Date Added | 2026-10-16 |
| Status     | Idea       |
| Target     | Post-MVP   |
| Type       | Spike      |

## Goal

Research how writing assistance could help users find common names and scientific names and draft
interesting plant descriptions.

## Initial scope

- Explore feasible on-device and optional external approaches, considering factual reliability, user
  control, privacy, offline availability, and cost.
- Deliver findings and a proposed scope for a separate implementation decision.
- Recording this spike does not approve a provider, dependency, network integration, or paid
  service. Any proposal that changes current product constraints must first update the relevant
  product documentation.

## Open questions

- Which assistance is useful enough to justify implementation?
- Can an on-device approach meet the required quality and device constraints?
- How should users review uncertain suggestions, and what privacy or cost tradeoffs would an
  external option require?
