# I-002 — Configurable quick filters and advanced filtering

| Field      | Value      |
|------------|------------|
| Date Added | 2026-10-16 |
| Status     | Idea       |
| Target     | Post-MVP   |
| Type       | Feature    |

## Goal

Keep common inventory filters convenient while allowing more specific filtering and alternative sort
orders.

## Initial scope

- Let the user configure two or three quick-filter chips from Settings.
- Add a Filters button for additional sort orders and more dedicated filters.

## Open questions

- Should there be two or three configurable quick filters, and which options can be assigned?
- Which advanced filters and sort orders should be offered?
- How do filters combine, and which selections or preferences persist?
